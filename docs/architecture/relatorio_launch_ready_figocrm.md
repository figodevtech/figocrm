## Classificação final

**BLOCKER = 0.** O risco de iniciar o beta sem backup externo recuperável foi aceito pelo responsável do produto. Essa decisão não altera o fato técnico: uma perda do banco de produção agora pode ser irrecuperável. Não classificar Supabase Free, ausência de PITR, backup gerenciado, R2 ainda sem credenciais, restore humano, instalação física da PWA, E2E com LLM no GitHub ou alertas avançados como bloqueadores deste beta. Os controles existentes de senha, billing e acesso continuam ativos.

## Operação do beta

- Acompanhar diariamente `billing:report`, `billing:reconcile:asaas`, GitHub Actions e Vercel Runtime Logs/5xx; investigar divergências antes de qualquer correção. Confirmar periodicamente a configuração remota de senha mínima e o risco residual da API Auth direta.
- Quando houver credenciais R2, configurar bucket privado e secrets, executar backup remoto, validar retenção de sete dias e restaurar em ambiente isolado conforme o [runbook](../operations/runbook.md). Até lá, manter o aviso operacional de ausência de backup.
- Após qualquer novo merge, verificar deployment `READY` da `main`, SHA em `/api/health`, banco, billing e erros de runtime. Não realizar cobranças reais repetidas só para smoke.
